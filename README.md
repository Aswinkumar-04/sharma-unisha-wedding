# Sharma & Unisha | Wedding Invitation & Save the Date

An elegant, mobile-responsive wedding invitation website inspired by [gokul-greshma.wedding.zetron.in](https://gokul-greshma.wedding.zetron.in).

## ✨ Features
1. **Cinematic Opening Section**:
   - Fullscreen background video playback (`assets/sharma_unisha_video.mp4`).
   - "Open Invitation" action with glowing halo and floral flourish.
   - Smooth video playback with traditional auspicious background music (`assets/wedding-music.mp3`).
   - "Skip Intro" option.
2. **Main Wedding Details**:
   - Sacred Diya / Lamp SVG animation with glowing golden flame.
   - Couple Names: **Sharma & Unisha**
   - Save the Date: **20 November 2026**
   - Romantic Quote: *"True love cannot be found where it does not exist, nor can be denied where it does"*
   - Live Countdown timer to the wedding date.
   - Ceremony (Muhurtham) & Reception Celebration details with direct Google Maps integration.
   - Location cards and family blessings.
   - Interactive Photo Wall & Gallery with 3D tilt, zoom, and full-screen lightbox modal.
   - Interactive RSVP form with personal greetings toast.
   - Floating music controls (play/pause background audio) and back-to-top button.
   - Ambient golden dust and floating jasmine petals canvas effect.

## 🚀 How to Run Locally

### Option 1: Double-Click
Simply open `index.html` in Google Chrome, Microsoft Edge, or Safari.

### Option 2: Run with Local Server
In this folder, run:
```bash
npx serve .
```
or
```bash
npm start
```
Then open `http://localhost:3000` (or the port shown in your terminal).
